BAKEVY - VERKKOSIVUDEMO

KAYTTO
1. Pura ZIP kokonaan.
2. Avaa index.html tuplaklikkaamalla selaimeen.
3. Kokeile kakkukonetta, kuukausien vaihtoa, viikon varaustilan vaihtoa ja tilauskyselyn esikatselua.
4. Sivusto toimii myos puhelimella. Fontit haetaan Google Fonts -palvelusta, mutta varafontit toimivat ilman nettiakin.

TARKEAT DEMORAJOITUKSET
- Kuvat ovat paikallisia SVG-kuvituksia, eivat BakeVyn oikeita tuotekuvia.
- Tuotteet, hinnat ja viikon varaustilanteet ovat esimerkkeja.
- Kakkukoneen hinta on arvio, ei oikea tarjous.
- Varaustilan muutos tallentuu vain kayttajan selaimeen (localStorage), ei muiden nakyville.
- Lomaketta ei laheteta mihinkaan. Se tuottaa esikatselun ja kopioitavan tekstin.
- Some-linkit vievat palveluiden etusivuille, eivat BakeVyn tileille.
- Yrittajan esittelyteksti on osin paikkamerkki.
- Ei maksamista, tilauksen tallennusta, vahvistusviesteja tai tuotantokelpoista yllapitoa.

TIEDOSTOT
index.html - sivun rakenne
styles.css - tyylit ja mobiilinakyma
script.js - kakkukone, kalenteri ja lomake
assets/*.svg - paikalliset kuvitukset
CODEX-JATKO-OHJE.md - valmis jatkokehitysbrief
